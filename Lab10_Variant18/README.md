# Лабораторная работа №10 — Вариант 18
## Система заказов столовой

**Проект:** «Столовая — система заказов»  
**Технологии:** HTML5, CSS3, JavaScript  
**Запуск:** откройте `index.html` двойным щелчком. Интернет не нужен для логики приложения.

### Реализовано
- отображение меню из отдельного модуля данных;
- поиск блюд и фильтрация по категориям;
- добавление блюд в корзину, изменение количества и удаление;
- расчёт стоимости, сервисного сбора 5% и итоговой суммы;
- оформление заказа с проверкой имени и непустой корзины;
- история заказов, номер заказа, способ оплаты и смена статуса;
- сообщения пользователю и адаптивная вёрстка.

### Структура проекта
```text
Lab10_Variant18_Canteen/
├── index.html
├── style.css
├── README.md
└── src/
    ├── main.js
    └── modules/
        ├── menu.js
        ├── pricing.js
        ├── orders.js
        └── ui.js
```

### Модули и связи
```text
menu.js ───────────────┐
pricing.js ────────────┼──> main.js <──> ui.js
orders.js ────────────┘
```
- `menu.js` — данные меню и поиск блюда по ID.
- `pricing.js` — расчёт суммы, сервисного сбора и итога.
- `orders.js` — создание заказа, хранение заказов и изменение статуса.
- `ui.js` — отображение меню, корзины и таблицы заказов.
- `main.js` — обработчики событий и связь модулей.

### Примечание по запуску
Для запуска двойным щелчком используется подключение отдельных JavaScript-файлов через обычные `<script>` и общий объект `window.LunchlineModules`. Это позволяет работать при `file://`, где браузеры ограничивают ES-модули. Модули логически разделены, функции передаются между ними через именованные свойства объекта.

### Тест-кейсы
| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Добавить «Борщ» | Блюдо появляется в корзине, сумма 850 ₸ + 5% |
| 2 | Увеличить количество борща до 2 | Количество 2, сумма блюд 1700 ₸, сбор 85 ₸ |
| 3 | Удалить позицию из корзины | Позиция исчезает, сумма пересчитывается |
| 4 | Оформить пустой заказ | Заказ не создаётся, выводится сообщение |
| 5 | Оформить заказ с именем из 1 символа | Заказ не создаётся, выводится сообщение о проверке имени |
| 6 | Оформить корректный заказ | Заказ появляется в истории со статусом «Принят» |
| 7 | Изменить статус на «Готов» | Новый статус отображается в истории |
| 8 | Искать блюдо по слову «чай» | Отображается только соответствующее блюдо |

### Вывод
В ходе лабораторной работы создана клиентская система заказов столовой. Приложение демонстрирует разделение данных, бизнес-логики и интерфейса на отдельные JavaScript-модули, обработку пользовательских событий, валидацию и расчёт стоимости заказа.
