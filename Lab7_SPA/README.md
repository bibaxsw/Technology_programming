# Technology_programming — Лабораторная работа № 7

В репозитории находятся 20 отдельных папок — по одной самостоятельной реализации на каждый вариант из задания.

## Структура
- `01_Базовый` – `06_Basic`: базовые варианты 1–6.
- `07_Medium` – `15_Medium`: средние варианты 7–15.
- `16_Advanced` – `20_Advanced`: повышенные варианты 16–20.

В каждой папке есть собственные `index.html`, `style.css` и `app.js`.

## Запуск
Откройте `index.html` внутри нужной папки. Для публикации на GitHub Pages можно выбрать папку нужного варианта либо разместить файлы на соответствующем пути.

## Важно
Это учебные демонстрационные данные. Перед сдачей откройте каждую папку и проверьте её функциональность.
