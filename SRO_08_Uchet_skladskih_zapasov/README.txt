Мини-проект СРО № 8: «Учёт складских запасов»

Как запустить:
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в современном браузере (Chrome, Edge, Firefox).
3. Программа работает без установки и интернета.
4. Данные сохраняются в localStorage браузера на текущем устройстве.

Возможности:
- просмотр списка товаров и сводных показателей;
- поступление товара и увеличение существующего остатка;
- списание с проверкой, чтобы остаток не стал отрицательным;
- поиск по названию и категории;
- контроль низкого остатка (5 единиц и меньше);
- история операций;
- удаление позиции;
- проверка пользовательского ввода.

Учебные данные при первом запуске:
Кабель USB-C, Мышь беспроводная, Блок питания.
