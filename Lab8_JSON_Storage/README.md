## Задания

1. **Список покупок** (Базовый) — Добавление и удаление товаров, сохранение списка в localStorage.
2. **Персональная анкета** (Базовый) — Имя, группа и город; сохранение и восстановление полей формы.
3. **Настройки темы** (Базовый) — Переключение светлой/тёмной темы и размера текста с сохранением настроек.
4. **Счётчик посещений** (Базовый) — Увеличение числа открытий страницы и сохранение счётчика.
5. **Избранные книги** (Базовый) — Добавление и удаление книг с названием и автором.
6. **Черновик сообщения** (Базовый) — Автоматическое сохранение текста при вводе и восстановление после перезагрузки.
7. **Язык интерфейса** (Базовый) — Выбор языка интерфейса и сохранение выбранного языка.
8. **To-Do список** (Средний) — Задачи, статус выполнения, удаление и фильтр; массив объектов в JSON.
9. **Учёт расходов** (Средний) — Категория, сумма, дата; сохранение операций и расчёт общей суммы.
10. **Мини-дневник** (Средний) — Записи с датой, просмотр и удаление с использованием JSON и localStorage.
11. **Корзина магазина** (Средний) — Товар, цена, количество; сохранение корзины и расчёт итога.
12. **Таблица студентов** (Средний) — ФИО, группа, балл; добавление, удаление и восстановление строк.
13. **Планировщик занятий** (Средний) — Предмет, время и аудитория; сохранение расписания.
14. **Викторина** (Средний) — Вопросы из массива объектов; лучший результат в localStorage, прогресс в sessionStorage.
15. **Каталог фильмов** (Средний) — Название, жанр, рейтинг; добавление, удаление, фильтрация и сохранение.
16. **Канбан-доска** (Повышенный) — Карточки в колонках «План», «В работе», «Готово»; сохранение перемещений.
17. **Мастер заявки** (Повышенный) — Форма из трёх шагов: черновик в sessionStorage, итоговые заявки в localStorage.
18. **Бронирование комнат** (Повышенный) — Дата, время и помещение; сохранение записей и проверка конфликтов.
19. **Личный бюджет** (Повышенный) — Доходы, расходы, категории и месячная сводка; JSON и редактирование операций.
20. **Менеджер проектов** (Повышенный) — Проекты, задачи, статусы и сроки; вложенный JSON, поиск и удаление.

## Как запускать

1. Скачайте или клонируйте репозиторий.
2. Откройте нужную папку `task01`–`task20` в Visual Studio Code.
3. Запустите `index.html` через расширение **Live Server**.
4. Проверьте функции задания и обновите страницу, чтобы убедиться, что данные восстановились.
5. Для просмотра сохранённых данных откройте DevTools → **Application** → **Local Storage** или **Session Storage**.

Рекомендуется использовать локальный сервер, а не открывать HTML через `file://`.

## Что используется

- HTML — структура страниц.
- CSS — оформление интерфейса.
- JavaScript — события и логика.
- `JSON.stringify()` — сериализация объектов и массивов.
- `JSON.parse()` — восстановление объектов и массивов.
- `localStorage` — постоянное хранение данных в браузере.
- `sessionStorage` — хранение данных в рамках сессии вкладки.

## Проверка

Для каждого задания рекомендуется проверить:
1. Первый запуск без сохранённых данных.
2. Добавление корректной записи.
3. Обновление страницы и восстановление данных.
4. Удаление или изменение записи.
5. Пустой или некорректный ввод.
6. Содержимое хранилища в DevTools.

Фактические результаты и скриншоты следует добавить после запуска проекта в браузере.
