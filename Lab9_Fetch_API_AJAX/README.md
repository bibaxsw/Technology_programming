# Лабораторная работа №9 — Fetch API / AJAX

**Дисциплина:** «Языки и технология программирования»  
**Тема:** Асинхронные запросы Fetch API / AJAX  
**Проект:** 20 индивидуальных заданий, каждое в отдельной папке.

## Структура
- `task01` … `task20` — отдельные самостоятельные задания.
- В каждой папке: `index.html`, `style.css`, `app.js`.
- `index.html` — разметка; `style.css` — бордово-розовый минималистичный дизайн; `app.js` — логика запросов.

## Запуск
1. Распакуйте архив.
2. Откройте папку `Lab9_Fetch_API_AJAX` в VS Code.
3. Запустите нужный `taskXX/index.html` через расширение **Live Server**.
4. Нужен доступ к интернету: данные запрашиваются с `https://jsonplaceholder.typicode.com/`.

## Что используется
- `fetch()` и `async/await`;
- проверка `response.ok`;
- `try/catch` и сообщения о загрузке/ошибке;
- безопасный вывод пользовательских данных через `textContent` и DOM-элементы;
- повторные запросы, фильтры, сортировка, пагинация, `Promise.all()`, `AbortController`;
- адаптивная вёрстка и единая палитра: глубокий бордовый, пыльно-розовый и светлый фон.

## Задания
01. **Публикации** — Загрузить 10 публикаций с API и показать ID и заголовок.
02. **Пользователи** — Загрузить пользователей и показать имя, email, город и компанию.
03. **Список задач** — Показать первые 10 задач и визуально выделить выполненные.
04. **Альбомы** — Загрузить и показать первые 15 альбомов с номерами.
05. **Фотографии** — Показать 12 фотографий с миниатюрами и обработкой недоступных изображений.
06. **Публикация по ID** — Получить публикацию по введённому ID и показать заголовок и текст.
07. **Пользователь по ID** — Найти пользователя по ID и показать имя, город и компанию.
08. **Поиск публикаций** — Загрузить публикации и фильтровать их по заголовку без новых запросов.
09. **Фильтр задач** — Фильтровать задачи: все, выполненные, невыполненные.
10. **Публикации пользователя** — Выбрать userId и получить публикации этого пользователя.
11. **Комментарии** — Получить комментарии публикации по ID и показать автора и текст.
12. **Пагинация публикаций** — Переключать страницы публикаций через _page и _limit.
13. **Пользователи и публикации** — Загрузить пользователей; по кнопке подгружать публикации выбранного пользователя.
14. **Альбомы и фотографии** — Загрузить альбомы и показывать связанные фотографии при выборе.
15. **Сортировка публикаций** — Сортировать загруженные публикации по ID или заголовку и повторять запрос.
16. **Дашборд задач** — Посчитать выполненные/невыполненные задачи и фильтровать по userId.
17. **Пользователь → посты → комментарии** — Последовательно выбирать пользователя, публикацию и загружать комментарии.
18. **Статистика пользователей** — Параллельно загрузить пользователей и публикации и посчитать посты каждого.
19. **Умный поиск** — Искать публикации с задержкой ввода и отменой предыдущего запроса.
20. **Фотоальбомы** — Каталог альбомов и фотографий с пагинацией, состояниями и повтором.

## Примечание
API возвращает демонстрационные данные. Доступность API и загрузка миниатюр зависят от интернет-соединения. Если запрос не сработал, используйте кнопку повторной загрузки.
